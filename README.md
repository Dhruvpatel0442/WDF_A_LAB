# StudentHub Portal

## Project Description
StudentHub Portal is a simple multi-page website developed using HTML and CSS. It is designed to 
provide students with a central platform where they can access academic information, manage their 
profiles, register/login, view events, submit feedback, and contact the administration.

---

## Features

- Home Page
- About Page
- Login Page
- Registration Page
- Student Dashboard
- Student Profile
- Events Page
- Contact Page
- Admin Page
- FAQ Page
- Feedback Page
- Responsive Navigation Bar
- Modern CSS Design

---

## Technologies Used

- HTML5
- CSS3

## Modules

### Home
Displays the main page with navigation links to all pages.

### About
Provides information about the StudentHub Portal.

### Login
Allows existing users to log in.

### Register
Allows new students to create an account.

### Dashboard
Displays the student's dashboard.

### Profile
Shows student profile details.

### Events
Displays upcoming college events.

### Contact
Allows users to send messages.

### Admin
Provides an interface for managing students and events.

### FAQ
Displays frequently asked questions.

### Feedback
Allows users to submit feedback.

---

## How to Run

1. Download or clone the project.
2. Keep all HTML files and style.css in the same folder.
3. Open **index.html** in any web browser.
4. Navigate through the website using the menu.
